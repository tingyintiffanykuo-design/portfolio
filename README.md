# Portfolio working repo

Tracks the progress and decisions behind updating the portfolio at https://tiffanytykuo.webflow.io. Webflow is the published site; this repo is the working memory, so work can resume from any device.

## Start here

1. `PROGRESS.md`: current focus, decision log, parked items. Read this first.
2. `portfolio-spec.md`: the original positioning and DMS review spec (Oct 14, 2026).
3. `case-studies/<name>/`: one folder per case study, holding notes, open questions, and drafts.
4. `jobs/`: job descriptions being targeted, saved as source text.

## Working rules

- Never invent metrics, outcomes, or roles (spec section 7).
- Narrative sections are written by the owner; Claude supplies structure, prompts, and line edits. Factual blocks (role lines, tables, at-a-glance) can be drafted by Claude from the owner's answers, then edited by the owner.
- Record every decision in `PROGRESS.md` with a date and a one-line reason.
